자바스크립트 연산자, 제어문에 대한 내용정리

## 연산자

연산자는 하나 이상의 표현식을 대상으로 **산술, 할당, 비교, 논리, 타입, 지수** 연산을 수행해 값을 만든다. 연산의 대상을 **피연산자**라고 한다. 피연산자는 값으로 표현될 수 있는 표현식 이여야함. 또한 연산자와 피연산자로 이루어진 조합도 값으로 평가될 수 있는 **표현식**이다.

### 산술연산자

피연산자를 대상으로 **수학적 계산**을 수행하는 연산자. 산술연산이 불가능할 때 NaN을 반환. 산술 연산자는 피연산자 갯수에 따라 이항,단항 산술 연산자로 구분

#### 이항 산술 연산자

2개의 피연산자를 산술연산을 하여 숫자 값을 만든다. 이항 산술 연산자는 **피연산자의 값을 바꾸는 side effect(부수효과)** 가 없다.

즉, 산술 연산을 하면 값이 바뀌는 경우가 없고 언제나 새로운 값을 만들 뿐.

```
+,-,*,/,% 들이 있다.
```

#### 단항 산술 연산자

1개의 피연산자로 산술연산해 숫자 값을 만든다.

- ++, --는 값이 1증가, 감소 하지만, 피연산자의 값을 변경하는 부수 효과가 있다. 즉, 암묵적 할당이 이루어진다.
- ++,--는 위치에 따라 의미가 있다.
  - 앞: 먼저 증가시키고 다른 연산 수행
  - 뒤: 다른연산을 수행후 피연산자 값 증가.
- \+ 어떠한 효과도 없지만, 숫자타입이 아닌 피연산자에 \+를 사용하면 숫자 타입으로 변환하여 반환 - 값을 새로 생성해서 반환하는 것임. 피연산자가 변하지 않음.

```js
var x = "1";
console.log(+x); // 1
console.log(x); // "1" => 부수효과가 없다
console.log(+true); // 1
console.log(true); //true
console.log(+false); // 0
console.log(false);
console.log(+"hello"); // NaN => 문자를 바꿀 순 없음.
console.log("hello"); //hello
```

- \-연산자는 피연산자의 부호를 반전한 값을 반환한다. \+와 마찬가지로 숫자타입으로 변환해서 반환.

#### 문자열 연결 연산자

- \+연산자는 피연산자 중 하나이상이 문자열일 경우 문자열 연결 연산자로 동작한다.

```js
"1" + 2; //=>  '12' (문자열 연결 연산)
1 + "2"; //=> "12"

1 + 3; //=>4 (산술 연산)
1 + true; // => 2 (true는 1로 타입 변환)
1 + false; //=> false는 0 으로 변환
1 +
  null + //=> null 은 0 으로 변환
  undefined; // => NaN으로 숫자타입으로 변환되지 않음
```

참고로 \+와 \-는 모두 **타입 강제 변환**이 일어난다.

### 할당 연산자

우항에 있는 피연산자의 평가 결과를 좌항에 있는 변수에 할당한다. 좌항의 변수 값을 변경시키는 부수효과가 발생한다.

```
= += -= /= %/ 등이 있다.
```

#### 할당문은 표현식일까?

```js
var x;
console.log((x = 10)); // 10
```

할당문은 부수효과만 있을 뿐 값으로 평가가 안될것 처럼 보이지만, 할당된 값을 평가한다. 이러한 특징을 활용해 연쇄 할당을 할 수 있다.

```js
var a, b, c;
a = b = c = 0; // abc모두 0
```

### 비교 연산자

좌항, 우항 피연산자를 비교해 결과 값을 불리언 값으로 반환 주로 for, if와 같은 문에서 주로 사용됨.

#### 동등, 일치 비교 연산자

- == 동등 비교 : 좌항 우항의 값이 같음
- === 일치 비교 : 좌항 우항의 값과 타입이 같음
- != 부동등 비교: 좌항 우항의 값이 다름
- !== 불일치 비교: 좌항 우항의 타입과 값이 다름

```js
5 == 5; // true
5 == "5"; // true
```

이와 같이 ==과 !=는 자바스크립트 엔진에 의해 **암묵적 타입변환을 거친다음 비교한다**

따라서 동등 비교 연산자는 예측하기가 어렵고 실수하기도 쉽다. 잘 사용하지 않는 것이 좋다.

**주의**: ===연산에서 NaN을 서로 비교하면 false나온다. 숫자가 NaN인지 조사할려면, Number.isNaN을 사용하여 비교하자

##### ES6에서 도입된 Object.is

위에서 본것 같이 ===연산도 NaN와 같은 동일한 것도 다른 값이라고 평가한다. Object.is는 예측 가능한 정확한 비교 결과를 반환한다. 아래의 예제로 이해하자

```js
Object.is(+0, -0) + // 양의 0, 음의 0은다르니 false
  0 ===
  -0; // 이것을 구분 못함 => true

Object.is(NaN, NaN); // true
NaN === NaN; // false
```

#### 대소 관계 비교 연산자

피연산자의 크기를 비교하여 불리언 값으로 반환

```
< > <= >= 가 있다.
```

### 삼항 조건 연산자

조건식 평가 결과에 따라 반환할 값을 결정하는 연산자이다. 유일한 삼항 연산자이고, 부수효과는 없다.

조건식 ? true일때 반환값 : false일때 반환값

첫번째 피연산자가 true이면 두번째 피연산자를 반환하고 false이면 세번째 피연산자를 반환한다. 즉, 값의 평가는 두번째 아니면 세번째 피연산자로 평가된다.

조건식은 불리언 타입 값으로 평가될 표현식이다. 만약 불리언 타입이 아니라면 암묵적 타입변환으로 불리언으로 변한다.

```js
var x = 2;
var result = x % 2 ? "홀수" : "짝수";
console.log(result);
```

이 예제와

```js
var x = 2,
  result;
if (x % 2) result = "홀수";
else result = "짝수";
console.log(result);
```

이 예제는 의미적으로는 똑같다. 그러나 중요한 차이점ㅇ ㅣ있다.

삼학 조건 연산자는 **표현식의 값**처럼 사용할 수 있지만, if...else문은 표현식이 아닌 문이다. 따라서 값처럼 사용되지 않는다.

상황을 고려하여 맞는 전략을 선택하자.

### 논리 연산자

우항과 좌항의 피연산자를 논리연산 한다. 부수효과는 없다.

- || => 논리합
- && => 논리곱
- ! => 논리 부정

논리 부정 연산자는 언제나 불리언 값을 반환한다. 단 피연산자가 불리언 값이 아니면 암묵적 타입 변환하여 계산한다.

```js
!0 => true
!"hello" => false
```

논리합과 논리곱의 평가 결과는 불리언 값이 아닐 수 있다. 2개의 피연산자 중 어느 한쪽으로 평가가 된다.

### 쉼표 연산자

왼쪽 피연산자 부터 차례대로 평가하고 마지막 피연산자를 평가하고 평가가 끝마치면 마지막 평가 결과를 반환

```js
var x, y, z;
(x = 1), (y = 2), (z = 3); // 3
```

### 그룹 연산자

감싸는 그룹 연산자는 피연산자인 표현식을 가장 먼저 평가한다. 따라서 그룹 연산으로 우선순위를 조절 할 수 있다. 연산자의 우선순위가 가장 높다.

```js
10 * 2 + 3; //23

10 * (2 + 3); //50
```

### typeof 연산자

피연산자의 데이터 타입을 문자열로 반환한다. 총 7가지 문자열이다.

"number","string","boolean","undefined","symbol","object","function"

참고로 null은 object를 반환하는데 이것은 기존 코드에 영향을 줄 수 있기 때문에 생긴 버그이다. 따라서 null 타입을 체크하고 싶을 땐 일치연산(===)으로 비교하자

또한 선언하지 않은 식별자를 typeof하면 ReferenceError를 뱉는게 아닌 undefined로 평가된다.

```js
typeof undef; // undefined => undef를 선언한적 없음
```

### 지수 연산자

ES7에 도입된 지수 연산자는 좌항을 밑으로 우항을 지수로 거듭 제곱하여 숫자 값을 반환

도입되기 전엔 Math.pow라는 메서드를 사용함.

```js
2 ** (3 ** 2); // => 512
Math.pow(2, Math.pow(3, 2)); // 512
```

결합순서는 우항에서 좌항이다. 즉, 우결합성을 갖는다.

또한 음수 거듭제곱은 괄호로 묶어야 한다.

```js
(-5) ** 2; // 25
```

또한 다른 산술 연산자와 마찬가지로 할당 연산자로도 사용가능

```js
var num = 5;
num **= 2; //25
```

그리고 이항 연산자 중에서 우선순위가 가장높음

```js
2 * 5 ** 2; // 50
```

### 연산자 우선순위

여러개의 연산자로 이루어진 문이 실행 될 때 연산자가 실행되는 순서.

연산자 종류가 많기에 외울필요는 없고, 그룹 연산자가 항상 1등이니 명시적으로 조절하면 된다.

우선순위 링크는 MDN을 참고하자 [링크](https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Operators/Operator_precedence)

## 제어문

일반적으로 코드는 위에서 아래방향으로 순차적으로 실행된다. 제어문을 통해 실행의 흐름을 인위적으로 제어 할 수 있지만, 직관적인 코드의 흐름을 혼란스럽게 만든다.

### 블록문

0개 이상의 문을 중괄호로 묶은 것으로, 코드 블록 또는 블록이라고 부른다.단독으로 사용할 수 있으나 일반적으로 조건문, 반복문, 함수정의 할때 많이 사용한다.

그리고 블록문의 마지막엔 **세미콜론을 붙이지 않는다.**

### 조건문

조건문은 주어진 조건식의 평가 결과에 따라 코드 블록을 실행을 결정한다. 자바스크립트는 switch, if..else문 두 가지를 제공한다.

#### if...else 문

조건식 평과결과가 true일 경우 if문의 코드 블록이 실행되고 else문의 코드 블록이 실행된다.

참고로 if 문의 조건식은 불리언 값으로 평가되야되고, 만약 아니라면 암묵적 타입변환이 일어나고 결정한다. 조건을 추가하여 실행될 코드 블록을 늘리기 위해선 else if문을 사용한다.

- **else if와 else문은 옵션이다.**
- if문과 else문은 2번 이상 사용할 수 없지만 else if문은 여러번 사용할 수 있다.
- 블록내의 하나뿐이라면 생략 가능하다.

#### 삼항연산 vs if...else

삼항연산자는 단순히 조건에 따라 값을 결정하여 변수에 할당할 경우에는 가독성이 좋지만, 내용이 복잡하고 여러줄의 내용이 필요하다면 if .... else문을 쓰자.

#### switch

주어진 포현식을 평가하고 그 값과 일치하는 표현식을 갖는 case문으로 실행의 흐름을 옮긴다.
만약 맞는 경우가 없다면 default문으로 이동한다. default는 선택사항

```js
switch(식){
  case 표현식1:
    실행될 문
    break;
  case 표현식2:
    실행될 문
    break;
  default:
    실행될 문
}
```

switch문의 표현식은 숫자, 문자열로 평가되어도 된다. 즉, 참 거짓 보다 다양한 상황에 따라 실행할 코드 블록을 결정할 대 사용하면 가독성에 유리하다

break를 적지않으면 다음 표현식을 검사해 맞으면 실행한다. 따라서 그것을 막기 위해 break를 사용. default문은 일반적으로 맨 아래에 있어 break를 적지 않음.

### 반복문

조건식의 평과 결과가 참인경우 코드 블록을 실행하고, 조건식 다시 평가해 참이면 또 실행 반복하다가 거짓일 때 탈출한다.

#### for문

```js
for (변수선언; 조건식; 증감식) {
  실행블록;
}
```

for문을 정확하게 이해하는게 반복문의 시작이다.

참고로 선언,조건식,증감식은 모두 선택사항이나 모두 빼면 무한 반복문이 된다.

```js
for(;;){...} // ...무한 반복
```

for문안에 for문을 중첩하여 사용할 수 있다.

#### while문

주어진 조건식의 평가 결과가 참이면 코드 블록을 계속 반복 실행한다.

for문은 반복횟수가 명확할 때, while문은 반복횟수가 불명확할 때 많이 쓴다.

만약 조건식의 평과결과가 불리언타입이 아니면 암묵적 형변환을 하여 평가한다.

#### do while

코드 블록을 먼저 실행하고 조건식을 평가한다. 따라서 코드 블록은 무조건 한번이상 실행됨.

```js
var count = 0;
do {
  console.log(count);
  count++;
} while (count < 3);
```

### break문

레이블 문, 반복문, switch문의 코드 블록 외에 break문을 사용하면 SyntaxError가 발생한다.

**레이블문** : 식별자가 붙은 문

```js
foo: {
  console.log('foo');
  break;
  console.log(1);
}
```

참고로 레이블문을 사용하면 가독성이 안좋아지고 오류를 발 생시킬 가능성이 높다.

### continue 문

반복문의 코드블랙실행을 현 지점에서 반복문의 증감식으로 흐름을 이동시킨다.

## 느낀점

이번 장을 통해 다양한 연산자에 대해 배우면서, 연산 과정에서 어떻게 타입 변환이 이루어지는지에 대해 이해하게 되었습니다. 이전에는 "0이 아니면 모두 true로 간주한다"는 막연한 이해로 사용했던 것들에 대해, 암묵적 형변환이 어떻게 이루어져 true로 평가되는지 정확히 파악할 수 있는 능력이 생겼습니다. 제어문과 반복문에 대해서는 1학년 때 배웠던 내용을 다시 상기시켜주는 듯한 느낌이었습니다.
