## 채울 것

- [ ] 처음에 믿었던 기본값은 무엇이었나 — 어디서 그렇게 배웠나 (학습 시점의 버전은?)
- [ ] 첫 번째 오해: 무엇을 보고 그렇게 판단했나
- [ ] 첫 번째 정정: 무엇을 보고 뒤집었나
- [ ] 두 번째 오해 — 같은 걸 또 틀렸다는 게 이 글의 핵심이다. 왜 또 틀렸나?
- [ ] 빌드 로그의 `○`(static) / `ƒ`(dynamic) 심볼로 확인한 실제 동작 — 로그 원문 붙일 것
- [ ] dev 서버에서 본 동작과 `next build` 결과가 갈린 지점
- [ ] 교훈: **dev에서 관찰한 걸 운영까지 일반화하면 틀린다**
- [ ] 확장: 학습 시점의 지식과 실제 설치된 버전이 어긋나는 문제. 문서를 읽을 때 버전을 먼저 확인하는 습관으로.
